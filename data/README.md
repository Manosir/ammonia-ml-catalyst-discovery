# OC20 N* data provenance

The N* trajectories were downloaded from the OC20 per-adsorbate IS2RE release
for adsorbate ID 77.

The system-level metadata were generated from:

https://dl.fbaipublicfiles.com/opencatalystproject/data/oc20_data_mapping.pkl

The local mapping file was verified by complete overlap with the 12,123 local
trajectory IDs. All overlapping records had ads_id=77 and complete miller_index
and shift fields.
